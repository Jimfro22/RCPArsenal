# v0.15.3-alpha.27 — radial visual polish

The optional marker wheel now uses a quiet graphite segmented ring. A selected
sector has a theme-accent edge, light chevron and slot corners. Native marker
icons keep their existing size, positions and mapping. The center has a small
origin dot and no text; one 12px caption below the ring explains selection or
cancellation. Returning to the center clears selection emphasis. A paused
preview explicitly says the wheel remains armed and Escape cancels.

The instant key, separate wheel key, center release, Escape/right-click cancel
and Clear All retain alpha.26 behavior. Protected snippets, bindings, drivers,
input attributes and all other functional modules are unchanged. Selection still
extends past the artwork; screen-edge clipping uses the original press position.
Six reusable white alpha textures supply only presentation, with reproducible
geometry in `tools/build_radial_masks.py`; no marker art or fonts are bundled.

Offline regression and package checks do not establish native WoW rendering,
font fit, hardware input, combat permission, taint, targeting or placement
acceptance. Those checks remain open. CurseForge, tags and releases remain held.
