# RCP Arsenal 0.15.3-alpha.23

General's Morning Brew addon list now has three columns: clickable addon name, Important/Optional priority, and right-aligned local status. The separate Setup, How to enable, Details, Get addon and Check again action column is removed. Installed and enabled addons use the Arsenal accent; missing, disabled and uncertain entries are gray. Clicking any addon name opens its CurseForge copy-link dialog, including when the addon is missing or disabled. WoW does not launch an external browser.

This build also includes the existing alpha.21/alpha.22 main-branch changes: absent raid-layout placeholders survive Apply, General settings apply immediately, Personal Tools groups its detailed options into disclosures, and accepting resurrection offers during combat remains a separate opt-in. Saved preferences and the existing installation folder are preserved.

Validation includes offline Lua behavior and UI checks, syntax checks, package safeguards and a single-root install ZIP. These checks do not establish native WoW rendering, taint behavior or client acceptance. This is an alpha test build. External addons are not bundled; publication adds no license grant.
