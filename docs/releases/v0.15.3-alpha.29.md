# v0.15.3-alpha.29 — readable Death Recap preview and recorded health

Preview now opens a clearly fictional Arcane Mage encounter with a filled
selected-health bar, stepped example health, a healer event, timed Prismatic
Barrier and readable defensive/item states. Real captures use plain language
and collapse absent health/healing areas. Preview stays isolated from recording,
settings, inventory, history and live Share/reminder actions.

For an already verified explicit own recap ID, the existing bounded native
attempt also reads one public positive finite recap maximum and each public
finite nonnegative event health value. Real selected health uses that fixed
reference and discrete points; missing/invalid values stay unknown and above-max
raw values remain readable without clamping. No real curve, heal, before/after-hit
claim, zero endpoint or clock alignment is inferred. Association, subscriptions,
retry limits, default OFF and media stay unchanged.

See `docs/DEATH_RECAP.md` for the native acceptance cases. Offline fixtures do
not certify native pixels, secret behavior, ingestion, identity, taint or speed.
GitHub source/test-package work only; no CurseForge submission.
