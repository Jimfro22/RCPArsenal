Adds Arsenal's own optional **world/ground marker cycler** for Morning Brew testing. It starts **off**, assigns no keys, and opens no new panel on login.

Open **Quick Bar → World markers** or `/rcpa markers`. Build a numbered unique order, enable the tool, and use **Open Key Bindings → AddOns → RCP Arsenal — World markers** to assign separate **Place next world marker** and **Clear all world markers** actions. Repeated hardware presses attempt successive markers at the cursor and wrap. Clear all restarts at slot 1 while retaining the order. Disabling keeps the player's native bindings but makes both actions inactive.

Download **RCPArsenal-0.14.2-alpha.1-release.zip** under Assets. GitHub's automatic source archives are not the installer. Preserve SavedVariables when replacing the addon folder. In-game version is `0.14.2-alpha.1`; profile schema is 18, ability catalog 6, and packaged Interface remains 120100. The adjacent checksum and manifest identify this exact build.

Configuration and protected-action setup happen outside combat. Native secure actions handle placement/clearing; the addon does not grant raid permissions. In raids, leader or assist is required. A keypress advances the local sequence even if the game rejects placement. Reload during combat defers initialization until combat ends.

Lua syntax, offline marker/profile/snippet logic, native-binding structure, and packaging checks passed before publication. These do not verify actual native hardware dispatch, cursor/terrain placement, taint, party/raid permissions, or raid-combat behavior.
