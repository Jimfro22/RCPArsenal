# v0.15.3-alpha.26 — instant key and separate optional wheel

Place next always uses its existing instant cursor action on key down. It never opens the wheel, even with the old wheel setting enabled. Existing Place next/Clear bindings are preserved. A new optional wheel binding starts Unbound and is editable inline or in WoW keybinds; nothing is assigned automatically.

The separate wheel is hold/swipe/release. Center release cancels; a selected sector opens its native reticle for a later real ground click. Clockwise from top: square 1, triangle 2, diamond 3, cross 4, star 5, circle 6, moon 7, skull 8. Non-clickable artwork and secure selection share their origin/scale/order. Changed root position/dimensions/scale cancels release; preview clears stale highlights. The alpha.25 clickable architecture and persistent router are removed. One physical wheel key is supported, including modifier aliases; conflicts or unreadable key data disable only the wheel.

Alpha.24 activity/history/order/readability behavior and alpha.25 Raid Groups improvements are retained. Native input, focus, mapping, terrain/placement, taint and paused-preview recovery still need owner acceptance. This is a review candidate only. GitHub delivery, CurseForge, tags, releases and shared Page edits remain held pending separate coordination.
