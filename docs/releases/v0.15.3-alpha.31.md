# v0.15.3-alpha.31 — Death Log presentation polish

A clearer rail, tighter damage layout, quiet support stems and backed count/shield
badges make the grouped Death Log easier to inspect. The existing Sever default
and persistent selection remain; a dashed guide and HP ring/percentage identify
the selected event. Fatal and selected borders are distinct.

Native spell/item tooltip descriptions remain, with compact event/group details,
a Flash Heal heading and bounded placement around the recap. Synthetic healing
debt gains an explicitly layered amber hatch without moving the raw HP readout.
One Preview label and readable inert actions replace repeated fixture disclaimers.

Recorder, association, state/stock, catalog, markers and media are unchanged.
Real HP remains discrete and native/local clocks remain independent. No new
collectors or histories ship. Offline checks do not establish native rendering,
tooltip reflow, taint or performance. GitHub test delivery only.
