This alpha packages the unchanged **RCP Arsenal 0.14.1-alpha** source supplied by Jimfro. It establishes an installable baseline for Morning Brew testing. No new raid hub UI or features are included.

Download **RCPArsenal-0.14.1-alpha-baseline.1.zip** under Assets. GitHub's automatic “Source code” archives contain the repository and are not the addon installer.

The install ZIP contains one `RCPArsenal/` directory. Close WoW, back up the existing addon folder and SavedVariables, then replace only `Interface/AddOns/RCPArsenal`. Preserve the `WTF` saved profile. In game, open `/rcpa config`.

- In-game version: `0.14.1-alpha`; the `baseline.1` package label does not change it.
- Packaged TOC Interface: `120100`; profile schema 17; ability catalog 6.
- ZIP SHA-256: `fe0db7ce5357f5b3e33b8e5b65b1ad1d3e648526dcac446628819ae1b74021b1`.
- All 49 payload files match the original verified source ZIP. The adjacent manifest records the tagged Git commit and each file hash; the `.sha256` file verifies the installer.

This inherited build enables several HUD, demo, and Quick Bar options by default. The planned quiet, opt-in hub is future work. The capability HUD shows which players bring an ability; it does not track live remote cooldown readiness or actual buff uptime.

Packaging/source checks passed. No live-client compatibility or Windows installation success is claimed. Record the actual client build, addon version, and ZIP checksum when reporting issues. Known checks still needed include cold-login artwork, subgroup moves and changed-side whispers, countdown interference, and migrated profiles.
