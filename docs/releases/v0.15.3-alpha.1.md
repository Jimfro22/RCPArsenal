Repairs caption recovery and feature grouping after expanded Windows/WoW testing of **0.15.2-alpha.3** revealed blank captions and confusing settings ownership. This is a corrective alpha; native acceptance is still pending.

- Intended addon captions survive font replacement, with built-in bootstrap and optional fonts validated away from live labels. Visible controls rebind registered textures/fonts immediately on display, then use the existing bounded recovery queue. This removes a wait for the next warm-up timer; it does not establish that the native reload-only texture issue is solved.
- Six sidebar destinations organize Available Cooldowns, Addons & Versions, Quick Bar, World Markers, Personal Tools, and Profiles & Recovery. Bare `/rcp` opens Addons & Versions. Available Cooldowns starts Categories, with its HUD/inspection master and honest provider-coverage explanation fixed above four internal tabs. Legacy direct routes remain compatible.
- One roster table shows all seven addons together. Column-selected details preserve local descriptions, download/setup/profile actions and approved targets. Unknown/no response, partial/offline, missing/disabled/not loaded/pending reload, stale age and exact target comparisons stay distinct. Opening settings and the age ticker never inspect talents or query the group.
- Quick Bar remains independent. Fresh/unset provider-class coverage defaults ON. Every explicit Enable Quick Bar action also enables coverage for older profiles; you can turn coverage OFF separately afterward. Opening settings, normalization, asset recovery, disabling Quick Bar and profile import preserve the current choice. The flyout now has a compact labelled Ready Check instead of a decorative duplicate checkmark, with existing puck shortcuts preserved.
- Panic keeps its saved opt-in and explains Off, waiting for a visible HUD category, or Visible. Scanning explains inspection-off/no-work and active/paused/waiting states beside its separate strip switch. A resolved paused queue no longer leaves an empty strip visible.

The original media files are unchanged. Generic theme icons explicitly request linear filtering; the puck already used it. No higher-resolution source matching the original hex RP artwork was found. Native cold-start/reopen screenshots must establish caption visibility, texture recovery, logo sampling and usability. Offline tests are evidence for logic and packaging only.

Positions, anchors/scales, notes, profiles, keys, inspection cache, local addon targets, marker sequence and deliberate opt-ins are preserved. Available Cooldowns, Quick Bar, World Markers and other optional tools remain OFF on fresh setup. Raid Leader Mode is still exploratory and is not introduced. Schema **19**, catalog **6**, readiness protocol **1**, Interface **120100** and SavedVariables identity are unchanged. No reset, reinstall or installation-helper rerun is required.

Existing linked GitHub Desktop installs need **Fetch origin → Pull origin**, followed by fully exiting and restarting WoW. Confirm `/run print(RCPArsenal.VERSION)` shows **0.15.3-alpha.1**. For a manual install, use the named **RCPArsenal-0.15.3-alpha.1-release.zip** asset with one `RCPArsenal/` root; GitHub's automatic source-code ZIP is not the installer. Keep SavedVariables. See `docs/NATIVE_RENDERING_REPAIR.md` for the short native acceptance checklist.

Validation before publication: **15 Python tests**, **20 Lua module parses**, and **4,868 offline Lua assertions** across eight actual-module harnesses. Tagged CI repeats validation and creates the ZIP, SHA-256 sidecar and manifest with clean-tag provenance and per-file hashes. Public asset verification is recorded separately after publication.

No CurseForge upload or automation is performed by this release; broader owner native testing remains required before a separate CurseForge handoff. External addons are not bundled. Publication adds no license rights and preserves the owner's All Rights Reserved posture.
