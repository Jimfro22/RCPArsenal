# v0.15.3-alpha.28 — personal Death Recap test slice

An optional, default-OFF personal Death Recap freezes local successful casts,
last-alive cooldown/charge/item observations and separately named death-handler
observations. A compact Arsenal popup retains the last session page and keeps
Unknown distinct from supported facts. Native records require a bounded explicit
personal death-ID/session association; default recap selection is never trusted.
No HP/heal curve, full pre-fatal castability or survival verdict is inferred.

The shared local supply cache works independently of the consumable reminder.
Preview is inert. Share prepares the native composer; the bell confirms enabling
only the existing reminder master. Journal ships without unverified mappings.
The defensive catalog is a verified, runtime-gated subset across 40 specs.

See `docs/DEATH_RECAP.md` for workload bounds, diagnostics and client acceptance.
Existing marker modules/media and other optional-tool defaults are preserved.
This GitHub test build is not native acceptance. No CurseForge submission.
