# Northern Sky integration contract

Arsenal calls separately installed stock Northern Sky Raid Tools. No NSRT code, artwork, serializer, or communication implementation is redistributed. The reviewed release is [12.1.32](https://github.com/Reloe/NorthernSkyRaidTools/releases/tag/12.1.32), commit `1f737b68d84f724ba690f8797dae991c1c863ab7`.

Public reads/config are independently probed. Internal mutations require that exact packaged version, completed `LoadedProfile`, valid current player/profile/context, complete required API shapes, ordinary bounded data, and native out-of-combat/encounter/restriction guards. Unknown versions retain supported public reads and original settings. Arsenal does not install, enable, or force-load the base addon. Original settings can load NSRT's own optional UI only on the explicit Open action.

The public note getter returns personal then shared runtime text. A received shared note can differ from the saved library entry under ActiveReminder. Drafts remain in Arsenal until a deliberate local-copy action. A new unique note is imported without activation or overwrite-same-boss behavior, then explicitly selected. Current AutoShare must be off; turning it on later can send the active copy through NSRT. Arsenal supplies no share or event-synthesis path in this slice.

Saved-profile selection is read-only. Applying settings uses a new Arsenal-owned clone and preserves the current note/runtime bundle, anchored local geometry/sizes, and AutoShare; originals and other-character assignments stay intact. The implementation uses original public profile helpers and guarded version-pinned internal preservation/refresh. It keeps a local recovery record before mutation, verifies resulting ownership/state, and refuses rollback over intervening native/external changes. A session-only return/restore path and explicit Keep Current / Release Undo avoid stale-backup dead ends. Recovery text is reviewable/copyable before local release.

Placement writes only the displayed native anchor, offset, dimension, and font fields. No persisted generic reminder Scale API was found, so none is invented. Selected geometry is refreshed through original native methods. Arsenal's preview is a separate labeled sample and does not show/enable NSRT's real reminder. Native preview/drag ownership takes priority; finish the original gesture before applying conflicting changes.

Backups are finite/session-local, not a replacement for SavedVariables backups. Unsupported or too-large data fails with a reason rather than silently truncating. No mutation is queued to run after combat. A guarded next-frame display refresh is distinct from a deferred settings write. Live interoperability and failure recovery remain covered by NSRT_WINDOWS_TESTS.md, not claimed by offline tests.

Primary coupling points: [public profile methods](https://github.com/Reloe/NorthernSkyRaidTools/blob/1f737b68d84f724ba690f8797dae991c1c863ab7/NorthernSkyRaidTools/Profiles.lua#L840), [profile import](https://github.com/Reloe/NorthernSkyRaidTools/blob/1f737b68d84f724ba690f8797dae991c1c863ab7/NorthernSkyRaidTools/Profiles.lua#L928), [runtime note getter](https://github.com/Reloe/NorthernSkyRaidTools/blob/1f737b68d84f724ba690f8797dae991c1c863ab7/NorthernSkyRaidTools/Reminders.lua#L2708), [note import/selection](https://github.com/Reloe/NorthernSkyRaidTools/blob/1f737b68d84f724ba690f8797dae991c1c863ab7/NorthernSkyRaidTools/Reminders.lua#L2273), [callback and encoding helpers](https://github.com/Reloe/NorthernSkyRaidTools/blob/1f737b68d84f724ba690f8797dae991c1c863ab7/NorthernSkyRaidTools/Functions.lua#L385), and [native geometry](https://github.com/Reloe/NorthernSkyRaidTools/blob/1f737b68d84f724ba690f8797dae991c1c863ab7/NorthernSkyRaidTools/Reminders.lua#L2549).
