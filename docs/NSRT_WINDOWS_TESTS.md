All tests below remain pending in the actual game. Preserve independent SavedVariables backups for Arsenal and NSRT before testing. Keep the verified 0.15.0 foundation installer available.

Record exact WoW build, both addon versions, NSRT UI companion state, ZIP checksum, original/current profile keys, original note text, active note name, AutoShare, and the placement values being tested. Never publish actual team/private note text in a public bug report.

1. **Quiet optional lifecycle:** base absent, installed disabled, enabled not loaded, disabled pending reload, unknown/different version, UI companion absent/disabled/unloaded, Arsenal first, late base/UI load. `/rcp` and readiness still work. No addon auto-enable/load, profile write, overlay, talent scan, network share, or endless retry occurs merely by opening Setup.
2. **Entry and scope:** Addons → Northern Sky → Setup and `/rcp nsrt` open the pane with Addons selected and Back to Addons. Check base and UI states independently. Public original settings is an explicit action and can initialize its load-on-demand UI; acceptance does not prove the window is already visible. Other versions remain read-only where public functions work.
3. **Draft preservation:** shared and personal return order is correct. Receive a shared note whose runtime string differs from the saved ActiveReminder entry. Type a draft before NSRT loads; type while a new shared note/profile arrives; change focus/subviews. The draft remains. Dirty caption updates immediately. A conflict disables Apply; Review Current shows that snapshot's profile/name/text and the explicit Keep Draft + Use Reviewed Context action retains the draft.
4. **Local note copy:** with AutoShare off, explicitly Save Local Arsenal Copy and confirm. It creates/selects a unique local copy, leaves all existing team/library notes intact (including overwrite-same-boss enabled), and sends nothing through Arsenal. AutoShare on blocks apply with a meaningful route to original settings. Later enabling native AutoShare can send the active copy on a ready/pull check; the UI must not call the copy private.
5. **Note restore and stale escape:** restore the previous runtime shared string, StoredSharedReminder, and ActiveReminder including nil/empty differences. Type a new dirty draft after applying a local copy, then restore: the draft must survive and require review against the restored context before applying. A clean draft should reload the restored native note. An incoming note or other external change blocks blind undo. Keep Current / Release Undo changes no NSRT state and permits a fresh operation. This session-only undo does not survive reload; copy any recovery text before release/reload.
6. **Profile selection/copy:** selecting a saved name does nothing. Apply as Arsenal Copy requires confirmation, creates/activates a separate profile, preserves current note libraries/references/runtime strings, local anchored geometry/sizes including timer font sizes, and AutoShare. Original selected/current profiles and other-character assignments survive. Verify source ordinary settings apply, extra alert/aura datasets are not imported, and preserve/apply copy describes what actually changes.
7. **Profile native failure/recovery:** offline injection fixtures are not live acceptance. Test normal return to previous profile and source/current/clone changes before apply/undo. With a controlled development fixture, exercise errors before/after activation and display refresh, native callback mutation, missing hooks, and backup limits. Never adopt an external profile switch or overwrite a newer incoming note as rollback. The pre-operation recovery record remains copyable; unresolved recovery blocks further native writes until explicitly released after review. Verify actual original export and received shared/personal backups are usable in original settings.
8. **Placement:** test icons, bars, text, circles, shared/personal/extra note. Numeric offsets/native anchors and supported dimensions/font sizes apply only to the selected section. No fictional generic scale key is written. An ordinary labeled sample previews the entered geometry without showing/enabling the real NSRT reminder or changing its settings. Stop/subview/close/combat removes only Arsenal's sample. Restore Last and Keep Current / Release Undo behave truthfully with external changes.
9. **Native preview/drag ownership:** start original NSRT preview or drag/unlock a note/anchor. Arsenal must refuse conflicting mutations and explain how to finish/lock it. It must not stop, move, rebind, or take over the original gesture. Finish native work, refresh/review, and retry successfully. Test original note resizers after a profile replacement, since upstream closures can retain old table references.
10. **Limits and text:** test UTF-8, pipes/NSRT syntax, empty and near-64-KiB notes, long profile names, nil fields, cyclic/unsupported data in controlled fixtures, and a large existing library near the adapter backup cap. Reject a projected over-cap operation before mutation, or retain a readable/restorable result. Never silently truncate a note or report a stranded write as successful.
11. **Boundaries:** ordinary members can use supported local setup; leader gating applies to readiness queries, not unrelated local config. This alpha adds no share button, synthetic event, countdown, debug encounter, new reminder engine, or arbitrary in-fight push. Native scheduled reminder/received-note behavior still belongs to NSRT.
12. **Foundation regressions:** run HUB_WINDOWS_TESTS.md and WORLD_MARKER_TESTS.md. Explicit HUD/scans, independent puck, cold enabled-profile assets, personal preview/normal res/reminder, version transport, original raid engines, and native bindings remain unaffected.

Source/offline tests establish adapter decisions against controlled and pinned stock-method fixtures. They cannot establish native rendering, serializer behavior on real saved data, original UI readiness, profile persistence/rollback, taint, or two-client delivery in WoW.
